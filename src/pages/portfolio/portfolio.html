В качестве портфолио готов предоставить следующие свои проекты:

• Analog Postman

Легковесный веб-клиент для тестирования HTTP API, вдохновлённый Postman. Стэк технологий приложения: Next.js, React, MUI, TypeScript, Zustand, ESLint, Prettier, Husky.

• Справочник-спиннингиста

Веб-приложение для прогнозирования клёва рыбы и предоставления информации о водоёмах. Приложение основано на народных календарях клёва, литературе по рыбной ловле и личных наблюдениях автора. Стэк технологий приложения: HTML, CSS, JavaScript (ES6+) , Webpack.

• Global carbon dioxide emissions

Приложение, отображающее глобальные данные о выбросах углекислого газа по странам. Приложение использует локальный набор данных JSON и предоставляет фильтрацию, автозаполнение и сортировку для просмотра записей о выбросах за разные годы. Стэк технологий приложения: React, TypeScript, CSS, ESLint, Prettier, Husky.

• Веб игра «Нонограммы»

Интерактивная игра включает в себя несколько головоломок с красивым фоном в виде карпа кои и функцией таймера. Стэк технологий приложения: HTML, CSS, JavaScript.
